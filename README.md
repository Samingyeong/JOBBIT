# JOBBIT · Experience Pet

Windows에서 화면 위의 펫을 눌러 경험을 기록하고, ChatGPT로 정리한 경험을 Obsidian에 저장하는 앱입니다.

Python 3.11 이상을 설치한 뒤 [ExperiencePet/install_windows.bat](ExperiencePet/install_windows.bat)을 실행하세요. 앱 설정에서 사용할 로컬 Obsidian Vault를 선택하면 됩니다.

실행 방법, ChatGPT 연결, 로컬 플러그인 및 EXE 빌드 절차는 [Experience Pet 안내](ExperiencePet/README.md)를 참고하세요.
