# 설계와 남은 개발 과제

## 구현 완료 (소스 기준)
- 업로드된 단일 PNG를 애니메이션하는 Windows 투명 오버레이
- 걷기/기어가기/점프/창 가장자리 체류/휴식/잠자기/흰둥이 동행 상태
- 무작위 말풍선, 캐릭터 크기/동작 조절, 드래그
- 전체화면 감지, 우클릭 메뉴, 트레이, Ctrl+Alt+E, Windows 자동 시작
- 원본 메모 로컬 자동 저장, 관련 프로젝트/경험만 검색
- ChatGPT 앱/웹 handoff: 질문 프롬프트 복사 → 사용자 붙여넣기 → 최종 답변 수동 가져오기 → 승인 후 저장
- MCP 서버 연결 진단 (선택)

## 추가 개발이 필요한 항목
1. 걷기, 앉기, 잠자기, 기어가기 등 **각 자세의 독립된 투명 프레임**. 현재는 원본 한 장의 위치/회전/반전 애니메이션. 단독 짱구/흰둥이를 분리한 새 아트 리소스 확보 필요.
2. 브라우저 페이지 **DOM 헤더** 위치 감지. 현재는 활성화된 Windows 창 바운더리에 근사하여 체류하는 연출. DOM을 읽으려면 사용자 동의하에 브라우저 확장 등 추가 연결 필요.
3. **ChatGPT 앱과 자동 메시지 양방향 통신**. OpenAI API 없이 임의 외부 프로그램이 ChatGPT 계정의 대화를 읽거나 보내는 통합은 공식 지원 인터페이스가 확인되지 않았음. 현재는 명시적 복사/붙여넣기 방식. 자동 대화·자동 정리를 API 없는 상태에서 구현된 것으로 주장하지 말 것.
4. 다중 모니터 인식 및 윈도우 DPI 보정. 현재 주 화면 기준.
5. 실제 Windows 10/11, Python 3.12, 빌드된 EXE 및 옵시디언 MCP 플러그인과의 엔드투엔드 테스트.
6. 접근성 개선, 캐릭터 클릭 통과 처리, 사용자 정의 애니메이션 자산 교체 UI.

## 데이터 흐름
1. 메모 입력 → 950ms debounce → 해당 세션 소유의 원본 메모에 원자적 갱신.
2. ChatGPT 버튼 → 관련 노트 1~4개 발췌 → 규칙과 묶어 클립보드에 복사 → ChatGPT 앱 실행/포커스.
3. 질문 3~5개 및 최종 정리는 ChatGPT 창에서 진행. 사용자가 결과를 복사.
4. 미리보기 붙여넣기 → 사실 검토 → 최종 경험 노트 신규 생성.

## 안전 원칙
- 기존 노트 덮어쓰지 않기 (단, 자신이 만든 원본 일기는 입력 중 갱신)
- MCP 토큰 저장하지 않기
- AI 답변 임의 생성/수치 조작하지 않기
- 실패 시 Vault 저장 성공을 표시하지 않기
